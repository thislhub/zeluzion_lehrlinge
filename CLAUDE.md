# Zeluzion – Lernenden-Content (Arbeitsgrundlage für Claude)

## Kontext
- **Zeluzion**: kleine Videoagentur aus Schwyz. Inhaber & Producer: Mathis Zehnder.
- **Ziel dieses Repos**: Neues Standbein aufbauen – KMU aus der Region (Kt. Schwyz, später Zentralschweiz) Shortform-Content (TikTok/Instagram Reels/YouTube Shorts) anbieten, mit dem sie **Lernende finden**.
- Dieses Repo ist das gemeinsame Gedächtnis. Alles Wissen, jede Entscheidung, jeder Lead wird hier in Dateien festgehalten.

## Arbeitsregeln
- Sprache: Deutsch (Schweizer Schreibweise, «ss» statt «ß»).
- Antworten knapp, aber vollständig (Kosten sparen).
- Fakten immer mit Quelle (Link + Datum) festhalten. Annahmen klar als **Annahme** markieren.
- Neue Erkenntnisse sofort in die passende Datei schreiben, nicht nur im Chat.
- Entscheidungen als neue Datei in `entscheidungen/` (Format: `JJJJ-MM-TT-thema.md`).
- Nach jeder Session `LOG.md` ergänzen (Datum, was gemacht, nächste Schritte).
- Keine Personendaten von Lernenden/Minderjährigen ins Repo (nur Firmenkontakte).

## Struktur
| Ordner | Inhalt |
|---|---|
| `recherche/` | Markt, Zielgruppe, Konkurrenz, Quellen |
| `strategie/` | Positionierung, Geschäftsmodell, Roadmap |
| `angebot/` | Pakete, Preise, Leistungsbeschreibung |
| `akquise/` | Lead-Liste (`leads.csv`), Vorlagen für Mails/Anrufe |
| `produktion/` | Formate, Drehablauf, Checklisten, Einverständnis Minderjährige |
| `entscheidungen/` | Entscheidungsprotokoll |
| `LOG.md` | Sessionprotokoll |
| `TODO.md` | Offene Aufgaben, priorisiert |
